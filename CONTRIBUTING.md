# Contributing to LifeOS

## Development Setup
Read [Local Development](docs/05-development/LocalDevelopment.md) and the frontend/backend repository documentation before implementation.

## Workflow
Open or discuss an issue, update documentation for architectural changes, create a focused branch, add tests, and submit a pull request.

## Branches and Commits
Use `feature/<scope>-<summary>`, `fix/<scope>-<summary>`, or `docs/<summary>`. Use Conventional Commits, for example `feat(finance): add budget summary`.

## Pull Requests
Explain purpose, testing, accessibility/security impact, and documentation changes. Keep PRs small; obtain review and passing CI before merge.

## Standards
Follow [Engineering Principles](docs/03-engineering/EngineeringPrinciples.md), [Coding Standards](docs/03-engineering/CodingStandards.md), and [Documentation Standards](docs/03-engineering/DocumentationStandards.md).
