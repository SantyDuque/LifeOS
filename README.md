# LifeOS

LifeOS is a Personal Operating System for finance, habits, fitness, reading, study, goals, and analytics.

## Vision
Turn personal data into clear, trustworthy guidance for intentional self-improvement.

## Core Features
- Personal finance, habits, fitness, reading, study, goals, and analytics
- A unified dashboard and future intelligent insights

## Architecture Overview
LifeOS is an ecosystem of an Angular frontend, NestJS modular-monolith backend, PostgreSQL, Redis, background workers, and external integrations.

## Technology Stack
Angular, NestJS, TypeScript, PostgreSQL, Prisma, Supabase Auth, Redis, BullMQ, Angular Material, Tailwind, ECharts, Docker, and GitHub Actions.

## Repository Structure
- `LifeOS.front/` — Angular application
- `LifeOS.back/` — NestJS API and workers
- `docs/` — ecosystem documentation
